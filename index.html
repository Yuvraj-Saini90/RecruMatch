Deterministic NLP vs. Pure LLMs

Unconscious Bias Mitigation

Mathematical Equation 5.1: Explainable Multi-Criteria Scoring Formulation Convex Combination (Sum = 1.0) 
Final Score = w_req * S_req + w_pref * S_pref + w_exp * S_exp + w_edu * S_edu + w_sim * S_sim

Enterprise Default Weights:
  - w_req  = 0.40  (Required Skills: 40%)
  - w_pref = 0.15  (Preferred / Bonus Skills: 15%)
  - w_exp  = 0.15  (Experience Relevance: 15%)
  - w_edu  = 0.10  (Educational Qualification: 10%)
  - w_sim  = 0.20  (Contextual Semantic Similarity: 20%)

Where:
  S_req  = (|Skills_cand ∩ Req_skills|) / |Req_skills|
  S_pref = (|Skills_cand ∩ Pref_skills|) / |Pref_skills|
  S_exp  = min(1.0, E_cand / E_min)
  S_edu  = Academic Tier Assignment (Ph.D. = 1.0, M.Tech = 0.90, B.Tech = 0.75, BCA = 0.50)
  S_sim  = (v_cand · v_jd) / (||v_cand|| * ||v_jd||)  [Cosine Similarity on TF-IDF sparse vector]
